## 👋 Sobre mim

Sou **Vinicius Herreira**, desenvolvedor full-stack em São Paulo e co-fundador da **[IDEON](https://www.instagram.com/ideonworks/)**, um estúdio que cria e opera os próprios SaaS.

Trabalho nas duas pontas: escrevo o código e decido o produto. Meu foco hoje é **software para clínicas** — gestão, agenda, WhatsApp e captação de pacientes — e sites rápidos para negócios locais.
